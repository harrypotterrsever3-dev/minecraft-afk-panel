## 🚀 Tek Tıkla Deploy (Ücretsiz)

### ▶ Railway ile Deploy Et (Önerilen)

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/new?template=https://github.com/harrypotterrsever3-dev/minecraft-afk-panel)

1. Yukarıdaki butona tıkla
2. GitHub hesabınla giriş yap
3. "Deploy" butonuna bas
4. 2 dakika bekle → sana bir `https://xxx.railway.app` linki ver
5. O linki telefona kaydet, bitir!

---

### ▶ Render ile Deploy Et

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/harrypotterrsever3-dev/minecraft-afk-panel)

1. Yukarıdaki butona tıkla
2. Render hesabı oluştur (ücretsiz)
3. "Create Web Service" seç
4. Deploy et → `https://xxx.onrender.com` linki al

## 📱 Telefonda Kullanım

Deploy sonrası aldığın linki tarayıcıda aç.

**Android'e uygulama olarak ekle:**
